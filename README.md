# Chaoxing Course Assistant (超星学习通自动刷课助手)

一款针对超星学习通（尔雅 / 泛雅）在线课程的自动化脚本，支持后台播放、多视频并发、任务点自动识别与章节跳转。

## 功能特性

- **多视频并发与协同调度**：页面内存在多个嵌入视频时支持并发播放；中央调度模块统一汇总播放状态，等待本节所有视频播放完毕后触发下一任务跳转。
- **任务点完成状态识别**：自动读取附件任务点状态（`.ans-job-icon` 与 `isPassed` 属性），已完成的任务点不重复播放；若当前章节全部任务点均已完成，自动跳转至下一章节。
- **文档与 PPT 自动阅读**：自动识别阅读器容器（`#viewerContainer` 及常见 PDF 视图），模拟滚动至文档底部并派发 `scroll` 事件，触发完成判定。
- **后台无感知播放**：通过代理 Page Visibility API（`document.hidden` / `document.visibilityState`）及媒体元素 `pause` 方法，防止切换标签页或最小化窗口时视频暂停。
- **导航防误触与空节点跳过**：监听手动点击事件，避免多次触发跳转；对无任务点的导读或文本章节，在等待加载缓冲后自动推进至下一节。
- **测验跳过与弹题处理**：自动跳过章节测验；视频内置弹出式测验自动选择并提交。
- **控制面板**：提供页面悬浮控制台，支持 1.0x - 2.0x 播放倍速调节、静音开关、画中画切换及手动导航。

## 技术实现

### 1. 后台防切屏机制
部分网课平台通过监听 `visibilitychange`、`blur` 以及定时器检查媒体播放状态。传统脚本常直接拦截 `EventTarget.prototype.addEventListener`，容易破坏浏览器与框架自身的网络生命周期，导致子框架资源加载中断或连接重置。
本项目采用以下方式：
- 伪造 `Document.prototype.hidden` 恒为 `false`，`Document.prototype.visibilityState` 恒为 `'visible'`。
- 保护性劫持 `HTMLMediaElement.prototype.pause`，在非用户主动暂停且非测验弹窗时维持播放。
- 采用独立 `Web Worker` 驱动巡检心跳，避免浏览器后台标签页降频。
- 引入低音量 `Web Audio` 上下文保活，降低后台标签页被系统挂起的概率。

### 2. 跨 Frame 多视频管理
超星课程卡片通常将多个视频分别置于独立的子 `iframe` 中。
- **状态采集**：每个视频所在框架生成唯一标识，定期向顶层窗口发送 `VIDEO_REPORT`。
- **中央调度**：顶层窗口汇总视频总数、已完成数量及最长剩余播放时长，并下发播放同步指令。全部视频达到完成标准后执行章节切换。
- **断点判断**：检查附件外层容器的 `.ans-job-finished` 类名及框架 `data` 属性中的 `isPassed` 标记，跳过已通过的任务点。

## 安装与使用

### 环境要求
- 浏览器：Chrome、Edge、Firefox 或其他基于 Chromium 的现代浏览器。
- 脚本管理器：[Tampermonkey](https://www.tampermonkey.net/) 或 [ScriptCat](https://docs.scriptcat.org/)。

### 安装步骤

**方式一：一键安装（推荐）**
- 在安装好脚本管理器后，点击此链接安装：[chaoxing-helper.user.js](https://raw.githubusercontent.com/Lngmate/chaoxing-killer/main/chaoxing-helper.user.js)

**方式二：手动安装**
1. 安装 Tampermonkey 扩展。
2. 打开 Tampermonkey 管理面板，点击「添加新脚本」。
3. 复制本项目中的 [`chaoxing-helper.user.js`](./chaoxing-helper.user.js) 代码并粘贴至编辑器中。
4. 保存脚本（`Ctrl + S`）。

### 使用说明
1. 登录超星学习通并进入课程学习页面。
2. 页面右上角将加载助手控制面板。
3. 脚本将根据当前页面任务点自动执行播放或阅读流程。

## 配置项

可通过控制面板调整以下运行参数（配置将自动持久化至本地存储）：

| 参数项 | 说明 | 默认值 |
| :--- | :--- | :--- |
| `enabled` | 自动连播总开关 | `true` |
| `skipQuiz` | 是否自动跳过章节测验 | `true` |
| `playbackRate` | 播放倍速（1.0x / 1.25x / 1.5x / 1.75x / 2.0x） | `1.0` |
| `muted` | 静音播放 | `true` |
| `jumpDelay` | 任务完成至跳转的缓冲时间（毫秒） | `4000` |

## 常见问题

**Q: 为什么某些视频加载后没有播放？**  
A: 脚本会检查该视频是否已取得完成标记（绿勾或 `isPassed: true`）。已完成的任务点会被直接跳过。

**Q: 为什么控制台剩余时间与某个短视频的时长不一致？**  
A: 当同一页面包含多个视频并发播放时，控制台以当前所有未完成视频中最长的剩余时长为准，确保所有视频全部结束后才触发跳转。

**Q: 手动点击下一节时是否会造成连跳？**  
A: 脚本在捕获阶段监听了页面导航与目录点击事件，用户手动切换章节时会即时销毁挂起的跳转计时器并设置 6 秒保护期。
